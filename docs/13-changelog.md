- 新增 WinForms portable、安装包、验证脚本和内存测量脚本。
- 记录 WinForms 预览版短启动基线，空闲 private memory 约 9.94 MB。
- 打磨 WinForms Dock 和设置页视觉：中性深色配色、圆角设置分区、更清晰的按钮和非紫色透明窗口绘制。
- 将 WinForms UI 改为更透明的玻璃 Dock、半透明设置页背景、轻量自绘控件和中文可见文案。
- 将 WinForms Dock 切换为 `UpdateLayeredWindow` 分层窗口绘制，使用真实 per-pixel alpha 透明，而不是色键透明。
- 新增文件夹 Flyout：文件夹 Dock 项支持直接子项网格、进入子文件夹、返回、资源管理器打开和文件夹面板设置。
- 明确 v0.2 产品边界：TidyDock 是手动管理的轻量启动器，不监控进程、不显示运行状态、不切换窗口、不索引文件夹。
- 优化 Dock 悬停放大：加入短时 ease-out 过渡和相邻图标连续缩放。
- 提升 Dock 图标质量：使用高分辨率 Shell 图标，解析 `.lnk` 目标，避免快捷方式箭头叠加。
- 新增文件夹自定义图标：通过 `DockItem.IconPath` 保存，图标资源复制到 v0.2 app data，并在设置页提供更换/恢复默认图标操作。
- 新增文件夹逐项打开方式：支持 `flyout` 和 `explorer`，文件夹快捷方式会规范为文件夹 Dock 项。
- 新增默认关闭的 `EnableDragReorder` 设置和中文开关，避免误触导致 Dock 项重新排序。
- 优化玻璃 Dock 背景：高透明度下使用更轻的填充、高光、阴影和描边。
- 修复设置页透明子控件导致的重绘残影、黑块和控件重叠。

## 2026-07-05 - 设置页与 Dock 解耦

- 设置页改为“草稿配置 + 预览 + 确定/取消”流程：打开设置页时复制当前配置，控件修改只写入草稿，不再即时保存或重绘 Dock。
- 新增配置深拷贝能力，覆盖 `DockSettings`、`FolderPanelSettings`、`Items` 和文件夹分组数据，避免设置页和运行 Dock 共用同一个配置对象。
- Dock 运行入口拆分为 `PreviewSettings`、`CommitSettings` 和 `CancelSettings`：预览只临时应用，确定才保存，取消会恢复打开设置前的 Dock 状态。
- 设置页底部新增固定操作栏：`预览`、`确定`、`取消`。
- Dock 项添加、删除、排序、重命名、图标样式、文件夹打开方式和分组管理均改为先修改草稿；点击预览后才反映到 Dock，点击确定后才写入配置。
- `跟随 Windows 启动` 仍作为系统级设置即时生效，不纳入 `AppConfig` 草稿流程。

## 2026-07-05 - 设置页状态反馈与配置保留

- 设置页底部新增状态反馈：`无未保存修改`、`有未预览修改`、`已预览，尚未保存`。
- `预览` 和 `确定` 按钮会根据草稿状态自动启用或置灰，避免重复预览和无变化保存。
- 设置页存在未保存修改或已预览但未保存状态时，点击右上角关闭会确认是否放弃修改并恢复打开设置前的 Dock 状态。
- 新增配置等价判断，用于区分草稿、上次预览配置和打开设置前配置。
- 默认卸载继续保留 `%APPDATA%\TidyDock\winforms` 用户配置，重装后可直接恢复。
- `Uninstall-CurrentUser.ps1` 新增 `-RemoveUserData` 参数，开始菜单新增 `卸载并清除配置 TidyDock` 入口。

## 2026-07-05 - 配置导出、导入与自动备份

- 设置页新增“数据与备份”区域，显示配置目录，并提供打开配置文件夹、导出备份、导入备份、恢复最近备份。
- 新增 `DataBackupService`，备份包包含 `settings.json`、`icons/` 和 `shortcuts/`，便于重装、换机和恢复自定义图标/托管快捷方式。
- 导入备份会先写入设置页草稿，用户仍需点击“预览”或“确定”才应用到 Dock。
- 每次保存配置前自动创建 zip 备份，并保留最近 5 份到 `%APPDATA%\TidyDock\winforms\backups`。

## 2026-07-05 - 产品体验 P0 优化

- 空 Dock 或仅包含设置项时显示首次使用入口：`添加应用/文件`、`添加文件夹`、`打开设置`。
- 右键移除 Dock 项前增加确认，明确只从 Dock 移除，不会删除原文件或文件夹。
- 文件、应用、文件夹目标不存在时显示警示标记，并支持点击或右键 `重新定位目标`。
- 设置页底部按钮文案改为 `预览到 Dock` 和 `保存并关闭`，降低草稿流程理解成本。
- 用户指南同步 WinForms v0.2 真实流程，弱化旧版“编辑模式”叙事。
